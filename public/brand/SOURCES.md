## Generated brand treatments — 2026-09-06
The original Instagram logo was supplied as a reference to each image generation.
- hero-monogram.jpg: dimensional white/red D in a dark studio; used in hero.
- monogram-relief.jpg: black embossed D with red lower-left element; used in About.
- lockup-dark.jpg and lockup-light.jpg: generated horizontal wordmark treatments. These are proposed treatments based on the existing identity, not official source originals. Dark lockup has an opaque black background.
Original lossless assets and exact prompts are retained in the workspace outputs/designario-brand-variants folder. JPEG derivatives only change encoding for web delivery.

## Blender studio loop — 2026-09-06
`designario-motion.mp4` and `motion-poster.jpg` are rendered from a real Blender scene built against the original logo silhouette. White satin shell and red lacquer inset, fixed camera, periodic object rotation and a moving studio light. 192 frames at 24 fps, 720x720, 8 seconds, no audio. The previous generated hero image remains archived but is no longer used by the hero. The About relief image is unchanged.
The editable Blender scene and reproduction script are delivered separately in outputs/designario-motion-blender.zip.
